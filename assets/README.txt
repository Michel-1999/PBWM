=======================

Drop your real images here using these EXACT filenames to replace the built-in
fallbacks. No code changes needed — the app picks them up automatically.

  logo.png        Brand logo (the temple / pediment mark). Until present, a clean
                  inline SVG temple renders in the header and sidebar.

  rm.jpg          Relationship Manager (Herr Wyss) — shown in the "Logged in as"
                  strip on the Relationship Manager page. Fallback: "HW".

  principal.jpg   Hans Mueller (Vater / principal). Fallback: "HM".

  spouse.jpg      Margrit Mueller (Mutter / spouse). Fallback: "MM".

  heir.jpg        Lukas Mueller (Sohn / heir). Fallback: "LM".

Tips
----
* Portraits look best square (>= 256x256); they are cropped to a circle.
* Every fallback is brand-consistent (forest green + serif initials), so the app
  looks polished immediately, before any image is added.
* All persons are fictional; do not use real client photos.
